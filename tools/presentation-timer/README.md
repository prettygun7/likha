# 발표 타이머 (부서별 15분 제한)

부서별 발표 진행 시 PowerPoint 슬라이드쇼 **위에** 작은 카운트다운을 띄우기 위한 도구.
용도에 따라 두 가지 중 선택한다.

| 방식 | 파일 | 특징 | 권장 상황 |
|---|---|---|---|
| A. 윈도우 오버레이 | `발표타이머.bat` + `PresentationTimer.ps1` | 전체화면 슬라이드쇼 위에 항상 표시. 클릭해도 포커스를 빼앗지 않아 방향키로 슬라이드 계속 조작 가능 | 발표자 PC 1대로 진행할 때 (기본 권장) |
| B. 웹 페이지 | `timer.html` | 부서명·소요시간 기록, 프리셋, 알림음. Edge/Chrome에서는 '항상 위로 띄우기'(문서 PiP)로 오버레이 가능 | 듀얼 모니터·태블릿 별도 표시, 또는 진행 기록이 필요할 때 |

---

## A. 윈도우 오버레이 (PowerShell)

### 실행
1. `PresentationTimer.ps1`과 `발표타이머.bat`을 **같은 폴더**에 둔다.
2. `발표타이머.bat` 더블클릭 → 화면 우측 상단에 타이머가 뜬다.
3. 다른 제한시간으로 열려면 명령 프롬프트에서 `발표타이머.bat 20` (20분).

### 조작
| 동작 | 방법 |
|---|---|
| 시작 / 멈춤 | `시작` 버튼, 또는 시간 숫자 더블클릭 |
| 리셋 | `리셋` 버튼 (설정된 제한시간으로 복귀) |
| 제한시간 조정 | `-1분` / `+1분` |
| 위치 이동 | 창을 드래그 |
| 투명도 변경 | 시간 숫자 위에서 **우클릭** (92% → 70% → 100% 순환) |
| 종료 | `닫기` |

### 표시 규칙
- 5분 이하 : 숫자 **주황**
- 1분 이하 : 숫자 **빨강 점멸**
- 0초 도달 : 배경 **적색**, 알림음 1회, 이후 초과시간을 `+MM:SS`로 누적 표시
- 하단 진행 막대로 경과 비율 표시

### 옵션
```
powershell -ExecutionPolicy Bypass -File PresentationTimer.ps1 -Minutes 15 -NoSound
```
- `-Minutes` : 제한시간(분), 기본 15
- `-NoSound` : 종료 알림음 끄기

### 동작 원리 / 주의
- 창에 `WS_EX_NOACTIVATE` 속성을 부여해 **클릭해도 포커스를 가져가지 않는다.** 따라서 슬라이드쇼 조작이 끊기지 않는다. 같은 이유로 키보드 단축키는 지원하지 않으며 마우스로만 조작한다.
- 2초마다 최상위(TopMost) 상태를 재선언하므로 슬라이드쇼 전환 시에도 가려지지 않는다.
- 그룹정책으로 PowerShell 스크립트 실행이 차단된 PC에서는 A 방식이 동작하지 않는다. 이 경우 B 방식을 사용한다.
- Windows 전용. (Windows 10/11 기본 PowerShell 5.1에서 동작, 추가 설치 불필요)

## B. 웹 페이지 (`timer.html`)

브라우저로 `timer.html`을 열면 된다.

| 동작 | 단축키 |
|---|---|
| 시작 / 일시정지 | `Space` |
| 리셋 | `R` |
| 다음 발표 (기록 저장 후 리셋) | `N` |
| 전체화면 | `F` |

- 제한시간 프리셋 5 / 10 / 15 / 20 / 30분
- `다음 발표`를 누르면 부서명·제한·실제 소요·증감이 **진행 기록** 표에 누적된다. 회의 종료 후 실제 소요시간 집계에 사용.
- **항상 위로 띄우기** : Edge·Chrome의 문서 PiP(Document Picture-in-Picture) 기능으로 작은 창을 분리해 슬라이드쇼 위에 띄운다. 미지원 브라우저에서는 버튼이 표시되지 않는다.
- 기록과 설정은 해당 브라우저에만 저장된다(localStorage). 다른 PC로 이전되지 않는다.
